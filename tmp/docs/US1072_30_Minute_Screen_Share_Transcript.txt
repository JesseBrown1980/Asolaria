15–18 min — Workflow Walkthrough (Core Logic)

Screen action:
- Scroll to Background Job Workflow diagram

What you say:
“Let me walk through a single run step by step.

First, the job starts — by default every 15 minutes.

It queries CSI Nursing Note submissions that haven’t already been successfully uploaded.

For each unprocessed submission:
- Create a tracking record in Pending state
- Resolve the patient using MRN
- Call AlayaCare to generate the PDF
- Upload the PDF to CareTend
- Update status to Success or Failed

This gives us full traceability for every submission.”


18–21 min — Duplicate Prevention & Status Flow

Screen action:
- Scroll to Status Flow
- Scroll to Database Changes

What you say:
“Duplicate prevention is handled through the tracking table.

Each ClientFormSubmissionId is stored once and indexed as unique.
If a submission has already been successfully uploaded, it’s skipped automatically.

Statuses move from Pending to Success or Failed, with retries up to a configurable limit.

This ensures idempotency — the same nursing note can’t be uploaded twice.”
