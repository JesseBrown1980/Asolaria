QDD $skip null Bug Fix — 2026-03-25
=====================================

BUG: Pagination aggregation pipelines pass raw `offset` and `limit` into
MongoDB $facet { $skip: offset, $limit: limit } instead of using the
null-safe defaults (`skip = offset || 0`, `docLimit = limit || 10`) that
are already defined in each function. When offset/limit are undefined
(no query params), MongoDB receives $skip: null and rejects with 500.

ROOT CAUSE: Copy-paste error in Brian's original code. Every search()
method creates safe defaults but the $facet pipeline references the
raw destructured values instead.
