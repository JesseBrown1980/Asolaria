=== /reports/new?type=single PAGE ANALYSIS ===

Source: apps/web-ebacmap/src/pages/reports/new.tsx

Query params:
  - type: "single" | "compound" | "ebacmap" — determines report type
  - template: optional template ID — loads pre-filled sections via getReportTemplate()

Required hooks/context:
  - useLocation() — current selected location (id + clientId)
  - useUser() — current user for permission check
  - withPermissions({ domain: Report, action: View }) — gate

Report data structure (what gets POSTed to /api/reports):
  {
    name: string (max 80 chars, required),
    client: location.clientId,
    location: location.id,
    showOnDashboard: false,
    reportType: "single" | "multi" | "ebacmap",
    access: "personal" | "facility" | "global",
    sections: [{
      title: string,
      filters: {
        interval, type (chartType), dataType, rollingInterval,
        conditions: [], facilityMapId, dateRange
      },
      charts: [{ module, groupBy?, limitLines, ... }],
      notes?: string (max 200 chars)
    }]
  }

Components used:
  - ReportSectionCard — wraps FilterDrawer + ReportBuilder + chart selection
  - FilterDrawer — fetches /api/filters?clientId=X&locationId=X&plans=bool&maps=bool
  - SaveReportTypeModal — visibility selector (personal/facility/global)
