Role Overview
Navitus is undergoing a major cloud and platform modernisation programme, moving critical pharmacy benefit management (PBM) systems into AWS and uplifting legacy .NET services into scalable, cloud-native architectures.
A major focus of this initiative is the modernisation of adjudication platforms that power high-volume pharmacy claims processing.
They are hiring an experienced AWS / Full Stack Engineer (.NET / C# / React) to take ownership of backend microservices, adjudication workflows, cloud infrastructure, and modern frontend delivery.
This is a hands-on contract role suited to engineers who can work independently, move fast, and deliver production-ready solutions in regulated healthcare environments.
The platform is built on a serverless AWS architecture supporting adjudication services, including technologies such as Lambda, API Gateway, RDS Cluster, DynamoDB, S3, Kinesis / Firehose, Glue, SQS, SNS, and EventBridge.
