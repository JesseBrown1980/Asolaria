## 1. WHAT IS SYMPHONY

Symphony is OpenAI's `openai/symphony` — an Elixir-based orchestration sidecar
that polls a Linear project for issues, creates isolated workspaces per issue,
and dispatches Codex agents to resolve them. Asolaria treats it as a MANAGED
SIDECAR SERVICE, not an external model provider. It serves as the "long-running
issue lane" in the Super-Swarm worker architecture.

Runtime: Elixir (escript via `mise`)
Default port: 4792
Linear project slug: asolaria-symphony-e3159fb1e260
