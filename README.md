# Asolaria

Asolaria is a local-first orchestration OS for agents, tools, policies, and proofs. This repository publishes the tracked public surface only. Private runtime trees, local topology, operator evidence, and live dashboard routes are intentionally excluded from this README.

## Public posture

- `47D` Brown-Hilbert is the live public base.
- `49D+` is a proposal overlay until formally signed.
- Public docs in this repo should link only to tracked `specs/`, `projections/`, `examples/`, `tools/`, and `docs/` paths.
- Release and promotion remain denied until public proof artifacts exist.

## What it is

Asolaria centers on:

- policy-first execution through hookwall
- Omnishannon + GNN as bounded planning and anomaly-routing layers
- white-room rebuild and append-only proof discipline
- BEHCS glyph and cube language as compact control surfaces
- vendor capsule ingest through sanitized examples rather than runtime exports
