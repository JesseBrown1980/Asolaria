## Recording checklist (before you press record)

1. Keep Chrome language and OAuth consent UI in English.
2. Use the exact app name/branding that appears in your OAuth consent screen.
3. Show real end-to-end OAuth grant flow with the same scopes requested in the project.

## Shot plan

1. Intro (0:00-0:10)
   - Show Asolaria landing/dashboard and state the app purpose.
2. Start user flow (0:10-0:30)
   - Trigger the feature that needs Google data access from within Asolaria.
3. OAuth consent flow (0:30-1:10)
   - Show full OAuth consent screen.
   - Pause on scope list and scroll if needed so all requested scopes are visible.
   - Continue through grant/allow.
4. Post-consent proof (1:10-1:40)
   - Return to Asolaria and show successful data usage tied to approved scopes.
   - Example: list Gmail messages, calendar items, or docs access from the approved account.
5. Data-use explanation (1:40-2:00)
   - State how data is used in-product and that it aligns with privacy policy disclosures.
