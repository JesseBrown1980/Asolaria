What's new in Atlassian for software teams
 
Explore Bitbucket Packages, AI‑powered code review, and more
  
In case you missed it, Bitbucket now includes a native package registry!
 
Create and manage container images, right in the same place where you manage your source code and CI/CD pipelines.
 
What are some of the benefits?
 
* Simplified permissions management: permissions for images and tags automatically cascade from the linked repository, allowing you to maintain a single, consistent set of permissions and access.
 
* Tool consolidation: reduce tool costs and management overhead by storing container images in Bitbucket, rather than integrating yet another platform.
 
* Unified billing monitoring: track costs and usage for all Bitbucket features, including Packages, network, and storage, in one place.
 
This is just the beginning! Coming soon, we'll launch immutable tags, enhanced integration with Bitbucket Pipelines, and support for package types such as npm, Maven, PyPl, and more.
 
Bitbucket Packages is available now and available to Standard and Premium Bitbucket Cloud workspaces.
